# Pendências — o índice

Cada pendência tem arquivo próprio (`PENDENCIA-*.md`), com o motivo, o que
precisaria ser feito e **o gatilho que a retoma**. Esta página existe para
responder "o que está em aberto?" sem abrir nove arquivos.

**Regra que vale para todas:** pendência sem gatilho vira lista morta. Se um
item aqui não disser *quando* voltar a ele, ou o gatilho está faltando ou o item
já não é pendência.

**Ao resolver, tire a linha daqui no MESMO commit** e feche o arquivo com uma
seção "Fechada" — o texto do achado fica, porque é ele que ensina. Não fazer isso
já custou sete dias de índice mentindo: `PENDENCIA-AUTOCASAMENTO-CRLF.md` e
`PENDENCIA-FOTO-CREDENCIAL-ARRANJO.md` foram consertados em 24/08 e continuaram
listados como vermelhos até 31/08. A suíte tem runner que acusa; este índice não
tem, então o fecho é passo do conserto e não tarefa para depois.
